A calmer way to talk through grief.

Lantern is a full-stack voice AI companion that lets a user speak naturally, converts speech to text, generates a supportive response, and speaks that response aloud. The current prototype focuses on the conversation experience itself rather than imitating or recreating a specific person.

System architecture

From microphone input to spoken response.

The prototype separates the public browser interface from the private API layer so credentials never ship to the client.

STEP 01

Capture

MediaRecorder captures microphone audio in the browser and packages it for upload.

›
STEP 02

Transcribe

The Flask API sends the audio to a speech-to-text model and returns a clean transcript.

›
STEP 03

Reason + respond

A language model generates a concise reply using recent context, tone selection, and safety instructions.

›
STEP 04

Synthesize

Text-to-speech generates audio for playback while the UI returns to a ready state for the next turn.

Product principles

Designed for a sensitive context.

The project treats transparency and boundaries as product requirements rather than fine print.

01

No identity impersonation

The current AI does not claim to be a deceased loved one or present generated content as that person.

02

Clear AI disclosure

The interface describes Lantern as an experimental AI companion, not a person, clinician, or crisis service.

03

Safety-aware responses

System instructions steer the model toward direct human and emergency support when immediate harm is expressed.

04

User control

Users can choose tone, clear the conversation, switch to text, and stop voice interaction at any time.
