Technical implementation

Built as a full-stack voice pipeline.

View repository
Frontend

JavaScript + Web Audio

MediaRecorder captures speech, Web Audio drives the live waveform, and the UI manages listening, thinking, speaking, and error states.

Backend

Python + Flask

A REST API validates requests, keeps the API key server-side, manages context, and orchestrates the AI services.

AI pipeline

STT + LLM + TTS

Speech is transcribed, recent context is included in response generation, and the answer is synthesized back into audio.

Resilience

Fallback-first UX

Typed input works when the microphone is unavailable, and browser speech can read replies if generated audio playback fails.

Safety note

If you are in immediate danger or may hurt yourself or someone else, contact local emergency services or a crisis service and reach out to a trusted person nearby. In the U.S., call or text 988.
