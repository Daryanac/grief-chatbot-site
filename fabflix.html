My contributions

From database to user experience.

My work spanned the backend, frontend, data workflows, and deployment configuration. The areas below reflect my contributions within the team project.

01 / Backend & data

Movie APIs and detail pages

Configured the MySQL data source and implemented movie and actor endpoints, movie-list and detail pages, and links between movies, actors, and genres.

02 / Authentication

Protected application flows

Implemented login and session authentication, protected pages and APIs, added password hashing and verification, and worked on prepared statements and reCAPTCHA verification.

03 / Discovery

Search and autocomplete

Built search by movie title, actor, year, genre, and title prefix. Contributed full-text search integration, autocomplete behavior, dropdown fixes, and fuzzy-search improvements.

04 / Operations

Employee tools and CSV imports

Implemented employee dashboard features, movie and actor entry, database metadata views, and a stored procedure. Built CSV import workflows with duplicate handling, validation, and inconsistency reporting.

05 / Checkout

Purchase and confirmation

Contributed shopping-cart endpoints and page integration, checkout, payment-detail validation, and purchase confirmation.

06 / Deployment

Sessions and service configuration

Prepared the application refactor, Redis-backed sessions, Dockerfile, and Kubernetes configuration. Added search-timing instrumentation to support performance analysis.

Technology stack

Java Servlets and JDBC connect the web application to MySQL. JavaScript powers the browser experience, with Redis session support and container deployment configuration.
